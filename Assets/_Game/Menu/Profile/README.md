# Perfil de piloto

Este módulo contiene el nombre de usuario, seis avatares vectoriales y el editor de perfil del menú principal.

- Los datos se guardan mediante `PlayerPrefs`.
- El nombre admite hasta 16 caracteres.
- La tarjeta `PILOTO ACTIVO` abre el editor de perfil.
- Los avatares se dibujan en UGUI y no dependen de imágenes externas.
