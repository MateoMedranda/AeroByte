# Fondos del menú

Coloca aquí las imágenes de fondo del menú principal.

Recomendaciones:

- Formato PNG o JPG.
- Relación de aspecto 16:9.
- Resolución recomendada: 1920x1080 o 3840x2160.
- No incluir botones dentro de la imagen.
- En Unity, importar como `Sprite (2D and UI)` y `Sprite Mode: Single`.

Asigna el sprite al campo `Menu Background` del componente `MainMenuController` en la escena `MainMenu`.
